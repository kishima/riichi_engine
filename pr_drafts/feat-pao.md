# 包（責任払い）を足す（ルールのキー pao）

ブランチ: `feat/pao`

## 何が足りないか

大三元・大四喜（ルールによっては四槓子も）を確定させる鳴きをさせた打牌者が、その役満の支払いを負う
「包」がありません。どの役満に包を付けるかがルールによって違うので、役満の名前の一覧をとるキーにし、
既定は空（今までどおり包なし）にしました。

## 再現（新しい spec）

`spec/mahjong/scoring/evaluators/pao_spec.rb`:

- 3 つ目の三元牌をポンさせた席が大三元の包として記録されること、既定のルールでは記録しないこと、
  RoundState の JSON に残ること（`pao_seats` の無い JSON は包なしで読むこと）
- 4 つ目の風牌の面子をポンさせた席が大四喜の、4 つ目の槓を大明槓させた席が四槓子の包になること、
  2 つ目までの三元牌では包にならないこと
- 支払い: 自摸は包の席が全額（積み棒も）、ほかの席からのロンは放銃者と包の席が半分ずつ（積み棒は放銃者）、
  包の席からのロンは包の席が全額、既定のルールや包の記録が無いときはふつうの支払い

## 直し

- `RuleConfig` に `"pao" => []`（`"daisangen"`・`"daisuushii"`・`"suukantsu"` を入れる）。
- `RoundState#pao_seats`（`{ 和了る席 => { 役満の名前 => 責任を負う席 } }`）を足し、`to_json`・`from_json` に入れました。
- `RoundFlow` はポン・大明槓の後、ルールにある役満について次の場合に責任を負う席（鳴いた牌の打牌者）を記録します:
  3 つ目の三元牌の面子（大三元）、4 つ目の風牌の面子（大四喜）、大明槓での 4 つ目の槓（四槓子）。
- `WinEvaluator` は、和了った役満にルールと記録の両方があれば、その分を `ScoreCalculator.calculate` の
  新しい任意の `pao:` に渡し、`winner_info[:pao]` に責任を負う席を入れます。
- `ScoreResult#score_changes` は包の分を次のように割り振ります。`payments` は手の値のままです。

| 和了 | 包の分 | 積み棒 |
|---|---|---|
| 自摸 | 責任を負う席がロンと同じ額を全額 | 責任を負う席 |
| ほかの席からのロン | 放銃者と責任を負う席が半分ずつ | 放銃者 |
| 責任を負う席からのロン | 責任を負う席が全額 | 責任を負う席 |

包でない役満が同じ手に重なっている分は、ふつうの自摸・ロンと同じに払います。

## ルール

大三元・大四喜の包と、自摸は全額・ロンは折半という分け方は、一般に打たれている決まりです。
四槓子の包は採らないルールもあるので、一覧に入れるかどうかで選べるようにしました。4 つ目の槓が加槓の
ときは包にしていません。

## 互換性

既定値（空）では記録も支払いも今までと同じです。RoundState の JSON に `pao_seats` が増えます（無い JSON も読めます）。

---

大三元・大四喜・四槓子の包（責任払い）を、ルールのキー pao（既定は空 = 包なし）で選べるようにした。自摸は責任者が全額、ロンは放銃者と折半。
