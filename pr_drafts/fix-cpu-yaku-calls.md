# CPU の鳴きと鳴いた後の打牌で、役の筋を見る

ブランチ: `fix/cpu-yaku-calls`（`fix/shanten-melds` の上）

## 何が誤りか

中級・上級の CPU（`NakiJudge.judge_normal`）は、鳴いた後の向聴数が下がればポン・チーをします。役があるかは
見ていません。門前でなくなった手にはリーチも門前自摸も付かないので、役牌の刻子も無く、断么九・混一色・対々和にも
向かえない鳴きをすると、テンパイしても和了れません。鳴いた後の打牌（`DahaiSelector`）も向聴数と受け入れだけを
見るので、断么九の手で么九牌を残す、などで役の無いテンパイになります。

あわせて、チーの組が複数あるとき（`available_actions` が `choices:` で返す）は、鳴く前後の比較で手から牌を
抜かずに数えていたので、どのチーでも向聴が下がって見え、`choices` のまま返していました（呼ぶ側は最初の組で鳴く）。

## 再現

- `cpu/analysis/yaku_plan_spec.rb`（新規）: 副露から残る役の筋、喰い断が無いとき、筋ごとの向聴数、対々和の向聴数
- `naki_judge_spec.rb`「役の筋」: 2 向聴の手で 1p を 2p 3p でチーすると 1 向聴になるが、123p で断么九が消え混一色も
  対々和も無いので鳴かない（中級・上級）。5m のポンは喰い断があれば鳴き、無ければ鳴かない。役牌の刻子がある手は
  どのチーでもよい。チーの組が 2 つ（123p と 234p）なら、断么九の筋の残る 234p で鳴く
- `dahai_selector_spec.rb`: 555m のポンの手で、断么九の筋で進む 9p を切る（中級・上級）。234p のチーの手で、
  123s を残した役の無いテンパイより、筋に沿った 1 向聴（1s を切る）を取る
- `base_ai_spec.rb`: 鳴いた手で、役の筋が消える暗槓（断么九の手で 9m）はしない。筋の残る暗槓はする

## 直し

- `Cpu::Analysis::YakuPlan` を足しました。副露から見て残っている役の筋を返します: 役牌（三元牌・自風・場風の刻子か
  槓子がある）、断么九（副露に么九牌が無い。喰い断があるときだけ）、混一色・清一色（副露が 1 つの色と字牌だけ）、
  対々和（副露がすべて刻子か槓子）。筋ごとの向聴数は、その筋で使えない牌を手から除いて数えます（対々和は刻子と
  対子の数から）。役牌の刻子がある手は、通常の向聴数です。
- `NakiJudge`: ポン・チーは、鳴いた後に筋が残り、筋に沿った向聴数が今より下がるときだけします。今の向聴数は、門前なら
  通常の向聴数、鳴いていればいちばん近い筋の向聴数です。チーの組が複数あれば組ごとに数え、選んだ組を `tiles:` で返します。
  「1 向聴以下なら鳴かない」は今までどおりです（鳴いた手では筋の向聴数で見ます）。大明槓は今までどおり選びません。
- `DahaiSelector`（中級・上級）: 鳴いた手では、筋に沿った向聴数がいちばん小さくなる打牌に絞り、そのうち通常の向聴数も
  同じになる打牌があればそれに絞ってから、今までどおり選びます。上級が他家のリーチに対して現物を探すときは筋を見ません。
- `BaseAi`: 鳴いた手の暗槓は、槓の後も筋が残るときだけします。`rule:` を `NakiJudge`・`DahaiSelector` に渡します。
- 初級（三元牌のポンだけ）は変えていません。

## 確かめたこと

CPU 4 人の半荘を 40 回ずつ（喰い断あり・赤 3 枚・ダブロンあり、ほかは一般的な既定）。前後とも、このブランチ以外の
修正をすべて入れた上で、この直しだけを足した前と後です:

| | 中級 前 | 中級 後 | 上級 前 | 上級 後 |
|---|---|---|---|---|
| 局数 | 469 | 430 | 465 | 409 |
| 鳴き / 局 | 2.97 | 0.94 | 2.94 | 1.00 |
| 局の終わりに鳴いた手が役の無いテンパイ（どの待ちでも役が無い）だった数 | 432 | 0 | 426 | 1 |
| そういう手が 1 つでもあった局 | 58.9 % | 0.0 % | 57.4 % | 0.2 % |
| 鳴いた手の和了率（鳴いた手のうち和了った割合） | 12.1 % | 28.9 % | 11.3 % | 23.8 % |
| 和了のうち鳴いた手の割合 | 35.5 % | 23.7 % | 31.4 % | 21.3 % |
| 荒牌流局 | 19.8 % | 7.7 % | 16.6 % | 11.0 % |
| 1 手の判断 中央値 / 95 % / 最大（ms） | 1.07 / 5.82 / 98 | 3.91 / 7.35 / 185 | 1.05 / 5.23 / 112 | 3.85 / 6.51 / 206 |

役の無いテンパイは、和了牌でロンしても自摸っても役が 1 つも付かない（偶然役とドラを除く）ものを数えました。
1 手の判断の中央値が上がったのは、門前の手が増えたためです（門前の手の打牌は前後とも約 4.2 ms、鳴いた手の打牌は
0.96 ms から 1.18 ms。半荘 6 回で分けて測った値）。最大値は、牌の多い色の並びを初めて数えるときのものです。

## 互換性

`NakiJudge.judge` と `DahaiSelector.select` に任意の `rule:` が増えます（省くと喰い断ありとして数えます）。
`NakiJudge.judge` がチーを選んだときは、組が 1 つでも複数でも `{ type: :chi, tiles: [...] }` を返します。
CPU の鳴きは減り、鳴いた手は役の筋に沿って打ちます。

---

中級・上級の CPU が役の無い鳴きをして和了れない手になっていたので、鳴いた後に役の筋（役牌・断么九・混一色・対々和）が残る鳴きだけをし、鳴いた手はその筋に沿って切るようにした。
