# 喰い替えの禁止をルールのキーにする（kuikae）

ブランチ: `feat/kuikae`

## 何が足りないか

ポン・チーの直後の打牌に制限が無く、鳴いた牌と同じ牌や、チーした順子の反対側の筋の牌（45m で 3m をチーして 6m）を
すぐに切れます（喰い替え）。喰い替えを禁じるルールが広く使われているので、選べるようにしました。

## 再現

`spec/mahjong/flow/rounds/kuikae_spec.rb`（新規）:

- 既定では、45m で 3m をチーした直後に 3m も 6m も切れる
- `kuikae: false` なら 3m と 6m が打牌の候補に出ず、`6m` の打牌は `InvalidActionError`（`kuikae is not allowed`）
- 45m で 6m をチーしたら 6m と 3m、嵌張のチー（35m に 4m）は 4m だけが切れない
- ポンの直後は鳴いた牌と同じ種類（赤五を含む）が切れない
- 鳴いた後に切れる牌が 1 枚も残らないチーは候補に出ない
- CPU は喰い替えにならない牌を切る

## 直し

- `RuleConfig` に `"kuikae" => true`（喰い替えあり、今の動き）。
- `RoundFlow.kuikae_tiles(state, seat, rule)`: ポン・チーの直後（自摸の無い打牌）の切れない牌の種類。ポンは鳴いた牌、
  チーは鳴いた牌と、鳴いた牌が順子の端なら反対側の筋の牌。
- 打牌の候補（`available_actions`）からその牌を除き、`ActionValidator` も同じ牌を断ります。
- `NakiDetector` は、切れる牌が残らない鳴きを出しません。
- `BaseAi` は打牌の候補の中から選びます（`DahaiSelector.select(..., allowed:)`）。

## ルール

喰い替えあり（今の動き）が既定です。禁止は現物（鳴いた牌と同じ牌）と筋（チーの反対側）の両方です。

## 互換性

既定値では今までと同じです。`DahaiSelector.select` にキーワード `allowed:`（省略可）が増えます。

喰い替え（鳴いた直後に同じ牌や筋の牌を切ること）を禁じるルールのキー kuikae を足した。
