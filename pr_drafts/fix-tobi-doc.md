# トビの境目を文書に合わせる（0 点未満で終了）

ブランチ: `fix/tobi-doc`

## 何が食い違っているか

`GameFlow.judge_next` は、`tobi` が真で誰かの点数が負（`negative?`）のときにゲームを終えます。
`state_machine.md` の図も「負の点数」です。一方 `api_reference.md` の RuleConfig の表は
「点数が0点以下でゲーム終了」と書いています。

## 直し

コードは変えず、`api_reference.md` の表を「0 点未満で終了。ちょうど 0 点は続行」にしました。境目の spec
（ちょうど 0 点では次局へ進む）を `game_flow_spec.rb` に足しました。

## ルール

0 点ちょうどは続行し、0 点未満で終了するのが一般に打たれている決まり（天鳳、M リーグ）なので、コードの方に
合わせました。0 点で終わる決まりも選べるようにするなら、別のキーにするのがよいと考えます。

## 互換性

動きは変わりません。
